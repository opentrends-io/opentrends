## 现场证据与修复

- 同一个公开接口旧 URL 返回 `CF-Cache-Status: HIT`、`Age: 147`、`max-age=14400`，前三来源译文记录均为 0；增加一次诊断参数的新 URL 返回相同报道的现成译文（30/30、10/10、20/20）。这次已实证是 HTTP 缓存挡住现成译文，不能归因于模型尚未生成。
- 列表响应改 `no-store`，Cache API 在查缓存前排除动态列表；新客户端使用稳定的 `translationCache=2`，退役此前四小时旧缓存，而不是每次加随机时间戳。SSR 与客户端同一版本。
- KV/内存仍缓存来源快照；命中未译页面时只读已保存的译文，用原文 hash、来源、ID、语言匹配。单快照同语言 10 秒合并读请求，不写 KV、不重建来源、不调用模型。
- 前端保留 10 秒查询间隔，译完立即停止；同一 query 最多 30 次成功读取、3 次错误后停止轮询。重新进入页面仍可读取，不通过刷新重置摘要预算。
