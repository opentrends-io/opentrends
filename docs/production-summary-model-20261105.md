## 防止再次遗漏

批准配置在 `packages/infra/src/production-model-policy.ts`。Alchemy 的 production 阶段或生产自定义域名必须使用该配置；旧环境里显式设置 Kimi 会在创建资源前报错。

上传版本后，先校验，再发布：

```sh
bun run deploy:production:api <candidate-version>
bun run deploy:production:api <candidate-version> --deploy --expected-current <active-version>
```

该命令核对模型、供应商地址、翻译模型；发布前确认现有版本仍为预期的单版本 100% 流量，发布后读回结果。单个命令有 120 秒截止时间，无自动重试。若发布结果不明，先读取部署状态，不重复发布。版本响应可能包含敏感绑定，命令不打印完整响应。

已对真实云端版本验证：旧 Kimi 版本被检查拒绝，新 Qwen 版本通过。主动变更模型需先修改并评审策略文件。

限制：直接在 Cloudflare 控制台或绕过脚本使用 Wrangler，仍能改配置；本批没有新增云端权限限制或监控任务。紧急回滚如涉及旧模型，必须明确记录临时例外，不能把旧版本重新当成长期生产基线。
